# 对象授权对照矩阵

| 入口 | 优先做的对照 | 判定线索 |
|---|---|---|
| REST 详情或下载 | 相同 A 对象，A 会话对比 B 会话 | B 获得 A 独有字段或文件标记。签名链接可能本来就是持有即授权，需核对签发与分享策略。 |
| GraphQL | 同一对象分别经业务查询和全局节点查询 | 比较授权错误和 data 中的字段，HTTP 200 无法单独判定。 |
| 批量接口 | B 的请求仅混入一个受控的 A 对象 | 核对逐项结果和实际状态。聚合成功可能掩盖被拒条目。 |
| 已删除或已撤权资源 | 在撤权前后重复同一读取 | 先区分产品允许的缓存或保留期，再查服务端是否持续返回私有内容。 |
| 父子对象 | 固定当前租户或父资源，替换为另一测试租户的子对象 | 检查父子关联和操作者授权是否在同一查询或事务中成立。 |

若 B 本来可通过组织关系、公开分享或委托访问 A 的对象，该请求可作为正对照。复测时去掉这些授权，用唯一的测试数据标记排除缓存和同名对象。
