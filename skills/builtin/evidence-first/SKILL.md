# 证据优先

- 每个目标断言前写入 `evidence/` 下真实文件。
- `assert_goal` 只引用已存在路径。
- History 用 title → summary → evidence 分层更新。
- 未通过证据闸门不得回复 DONE。

## 交接时复核已有证据

- 按目标核对断言时的证据版本。有封存附件时，以其字节和 SHA-256 核对引用。旧目标只有通过记录和路径时，分别写明「历史已通过」「原版无法复验」。同名工作文件可能已经更新。
- 遇到更正，写清复核意见、被撤回的原 Fact、适用目标，以及更正 Fact 自身的复核状态。沿用旧判断的汇总应标为待复核；已有独立复核的记录按该意见列示。只有部分材料时，注明缺哪个编号、版本或判据。
