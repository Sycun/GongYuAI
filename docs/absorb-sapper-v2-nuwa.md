## 结论（先读这四句）

1. 文中成绩与叙事支撑的是 **harness（分层史 + 交接 + 零策略看门狗 + 同族迁移）**，不是「tmux 军团 / 角色戏」产品形态。
2. 分层 History（标题 / 摘要 / 证据）明确 **参考 Cairn 意图图并分层优化**——你们已落地；勿再当新理论。
3. 「给基座不给手册」与你们「MCP/Skill=弹药、禁固定渗透剧本」同向；**不等于**禁 Skill/MCP（文中偏竞赛极简，你们产品保留弹药）。
4. **明确不抄**：女娲造人=tmux 开新 Claude、兵种涌现当默认 UI、示踪剂未开源设计、文明公理叙事进产品壳。

成绩口径（备注自注，引用时勿夸大）：

- TCH3 **初赛** 634 队第一（80.18 分/85 flag/8h 无人值守）；**决赛第 9**（同期投入 GeekCon，演进时间不足，最后一小时从第 12 追回）——架构可塑但需要塑造时间。
- TSEC Bench V1 全解 98.99 分；BCTF 未调优 82.55（赛后对照历史成绩，非正式参赛夺冠）。
- 授权目标 100+ 成功率 >60% 是**使用者反馈**，非独立第三方评估。
- 族级迁移两次爆发 ~46% 得分、a 系列 ~3 分钟/题——**同类迁移≠未见任务泛化**（备注明文）。
- token 10.3 亿 vs 45.8 亿：榜单条件未完全控制，不能单凭榜单把效果全归因架构。
- 旧稿「22 小时」与日历节点口径不一致，备注保留节点不采用总历时。

## 明确不吸收

- 把「女娲测试 / 文明公理」写成产品文案或验收标准。  
- tmux 军团、通信兵等角色戏为默认控制台。  
- 「零 Skill / 零 MCP」竞赛教条（与 [absorb-cairn.md](./absorb-cairn.md) 同拒）。  
- 未开源的示踪剂实现猜测或半吊子落地。  
- 用初赛分数替代 TSecBench / smoke 差分。

## 若再动手（非默认）

仅当差分证明有缺口时：

1. Relay 双阈值可对照文中 85% 写交接 / 90% 压缩（仍以图为权威）。  
2. 同族迁移 / Hint 投递继续压「3 分钟一题」类调度收益——已有工具，调 prompt/预算即可。  
3. 模型分层：Reason/Bootstrap 用强模型、Explore 用快模型——已升为 [dev-handbook.md](./dev-handbook.md) **P7 提案**（配置项，非架构改动），差分验证前不升默认。
