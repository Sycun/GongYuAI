概念演示（P8 提案）：上层全局记忆（用户级），下层项目记忆（任务级）。点击节点看模型规范。

两级记忆：项目记忆管过程，全局记忆管生涯

  • 项目记忆（任务级，已有）：History 黑板 + Relay π + Durable checkpoint + 证据封存。
  • 全局记忆（用户级，P8 提案）：档案索引（所有任务联邦可查）+ 蒸馏图谱（复核后的经验）+ 工具遗产 + Skill 演进。
  • 繁衍闭环：项目记忆 → 蒸馏 → 人审 → 注入新项目 → 反馈回写；跨层只有溯源指针与注入事件。
  • 无源不记忆；注入只走建议层，新任务 Intent 仍挂自己的 Fact——推荐≠授权。
